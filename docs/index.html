🎤 마이크 권한이 필요합니다

브라우저가 마이크 사용을 차단했습니다. 아래 안내대로 허용 후 페이지를 새로고침하세요.

📱 iPhone (Safari)

주소창 왼쪽 「가가」(aA) 탭 → 웹사이트 설정 → 마이크 → 허용

📱 Android (Chrome)

주소창 왼쪽 🔒 자물쇠 → 권한 → 마이크 → 허용

💻 데스크톱 (Chrome / Edge)

주소창 왼쪽 🔒 자물쇠 → 사이트 설정 → 마이크 → 허용

💡 잘 모르겠으면: 「파일 업로드」로 다른 앱(녹음기 등)에서 녹음한 파일을 올려도 됩니다.

😢 녹음을 사용할 수 없습니다

이 브라우저는 마이크 녹음(MediaRecorder)을 지원하지 않습니다.

  • iPhone: Safari 14 이상
  • Android: Chrome 49 이상
  • 데스크톱: Chrome · Edge · Firefox 최신 버전

대신 「파일 업로드」로 다른 앱에서 녹음한 파일을 올릴 수 있습니다.

⏱️ 통합 타임라인

환자/보호자 처치·활력징후 ~HH:MM 이후 = 시간 추정

시간축을 중심으로 환자 발화(왼쪽)와 구급대원 처치(오른쪽)가 흐릅니다. 시간이 명시되지 않은 발화는 발화 순서를 그대로 유지하고 직전 시간 기준으로 "~HH:MM 이후"로 표시합니다(추측 아닌 사실 표시).
